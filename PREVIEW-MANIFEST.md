# Preview manifest — /projects hover-play clips

Generated by `scripts/capture-previews.mjs`. Do not edit by hand: rerun the script so this file
cannot drift from the assets on disk.

## Toolchain

- Capture: Playwright `1.63.0` driving headless Chromium `153.0.8010.12` at 1440×900, recording with `recordVideo`.
- Post-process: `ffmpeg version 8.0.1`.
- Output: VP9 / WebM, 1280×720, 25 fps, `-an` (no audio track), CRF 32 preferred,
  two-pass bitrate-constrained at the same CRF when a clip busts 600 KB (hard cap 800 KB).
- Posters: PNG 1200×675, one per section, cropped from the same settled page.
- Ad hosts blocked during capture: `googlesyndication.com`, `doubleclick.net`, `googleadservices.com`,
  `adservice.google.com`, `amazon-adsystem.com`.
- Everything is free and open source. No watermark, no paid service, no subscription, no audio, no third-party iframes.
- A page that renders an error/not-found state or does not contain the expected content is retried and then refused:
  the script never writes a clip it could not verify.
- Scroll unlock: before recording, `html,body{overflow-y:auto !important;height:auto !important;overscroll-behavior:auto !important}`
  is injected (plus the same values as inline `!important` styles, and the same treatment for any large non-fixed wrapper that
  clips its own overflowing content). Several sites ship `body{overflow-y:hidden}`, which freezes the document in headless
  Chromium: the page then cannot scroll at all and every clip would be a still frame.
- Motion assertions, both hard: before recording the unlocked page must actually move by `600 px` (wheel-driven,
  programmatic fallback) or the clip is refused; after encoding the clip's mean per-frame luma delta must be at least
  `--min-motion` (default 2), measured with ffmpeg
  `tblend=all_mode=difference,signalstats` (`lavfi.signalstats.YAVG`, 0-255 luma units). A clip that fails is deleted and the
  run exits non-zero. This is why no shipped clip is a static frame.
- Consent overlays: declined where the site offers it (Google Funding Choices, TrustArc), then removed and re-swept;
  a late-injected overlay cannot appear in a recorded frame.

## Reuse and permission notes

- The clips are screen recordings of live sites Albert Olivé builds and operates, stored in this repository
  purely as portfolio previews of that work.
- Third-party content visible inside a recorded page (event listings, venue photos, weather data, store chrome)
  belongs to its respective owners; the clips are illustrative previews and are not relicensed.
- Garmin (`breathing-timer`): the clip is the live Connect IQ store listing; the poster is composed from official
  Garmin store imagery served by `services.garmin.com/appsLibraryExternalServices/api/` (app icon
  `806f54bd-339a-4a34-b4ef-9e32f13113d6` plus the three official preview screenshots), used unmodified as store imagery.
- moveflow: captured from and linked to `https://moveflow-site.vercel.app`, the real project.
  `https://moveflow.app` serves an unrelated product ("MoveFlow – Business Management Platform", OOMI Software),
  so the card does not link to it.
- Consent overlays are declined/dismissed and ad containers removed before recording, so no consent state and no
  advertising is recorded.
